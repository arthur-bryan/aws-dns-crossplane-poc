# Backstage — APE DNS

Scaffolded Backstage app wired to the DNS scaffolder templates. Opens a PR
against this repo whenever a template is submitted; ArgoCD then syncs the new
entity YAML after the PR is merged.

## Prerequisites

- **Node 22 or 24** (Backstage's `engines` requirement). The `isolated-vm`
  native dep fails to build on Node 20. A `.nvmrc` pin is included.
- **yarn 4.x** (auto-provisioned by corepack under Node 22).
- A **GitHub PAT** with `repo` scope, exported as `GITHUB_TOKEN`.

```bash
# one-time (user-land, no sudo)
curl -s -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
source ~/.bashrc   # or open a new shell

cd lab/backstage
nvm install
corepack enable yarn
```

## First run

```bash
cd lab/backstage/ape-lab

# dependencies (once)
yarn install

# lab config (once) — copies the committed template
cp ../app-config.example.yaml ./app-config.local.yaml

# start with PAT in env
export GITHUB_TOKEN=ghp_your_token_here
yarn start
```

Backend: `http://localhost:7007` — Frontend: `http://localhost:3000`

## What's wired

- **`app-config.local.yaml`** (gitignored) and **`../app-config.example.yaml`**
  (committed) mirror each other. The local copy resolves `${GITHUB_TOKEN}` at
  runtime.
- **Catalog locations** resolved relative to `packages/backend/` (backend cwd):
  - `../../../../../entities/catalog-info.yaml` — Domain/SubDomain/System/Environment seeds
  - `../../../../backstage-templates/catalog-info.yaml` — the three DNS Templates
- **`packages/backend/src/index.ts`** registers
  `@roadiehq/scaffolder-backend-module-utils` so templates can use
  `roadiehq:utils:fs:write` and `roadiehq:utils:merge`.

## Gitignored artifacts

Everything generated by `yarn install` or `yarn build`:
- `ape-lab/node_modules/`
- `ape-lab/packages/*/dist/`, `dist-types/`
- `ape-lab/.yarn/`
- `ape-lab/app-config.local.yaml` (contains PAT reference)

Committed from the scaffolded app:
- `ape-lab/package.json`, `ape-lab/packages/**/src/`, `ape-lab/*.yaml`, lockfile.

## Troubleshooting

**`isolated-vm` build error `v8::SourceLocation does not name a type`**
You're on Node 20 or older. Switch to Node 22: `nvm use 22` then `yarn install`.

**`Cannot find module '@roadiehq/scaffolder-backend-module-utils'`**
Run `yarn --cwd packages/backend add @roadiehq/scaffolder-backend-module-utils`.

**`GITHUB_TOKEN` env var not picked up**
Backstage reads it at process start. Export before `yarn start` (or put it in a
local `.env` and source it).

**Scaffolder fails `publish:github:pull-request`: 401/403**
PAT missing the `repo` scope, or expired.

**Templates don't appear in catalog**
Check the catalog-info target paths in `app-config.local.yaml` resolve from
`packages/backend/`. They are 5 levels up to reach the repo root.
